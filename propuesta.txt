1. Introducción

La planificación de horarios académicos es una tarea compleja que requiere tener en cuenta múltiples restricciones, como la disponibilidad de profesores, la asignación de aulas, la duración de las clases y la no superposición de asignaturas. Actualmente, muchas instituciones educativas gestionan esta información en documentos PDF o fichas individuales, lo que dificulta la detección automática de conflictos.

Este TFG propone el desarrollo de una aplicación que permita cargar horarios y fichas de asignaturas en formato PDF, extraer la información relevante y detectar posibles restricciones o conflictos de forma automática.
2. Objetivos

    Diseñar y desarrollar una aplicación web o de escritorio que permita:
        Cargar documentos PDF con horarios y fichas de asignaturas.
        Extraer y estructurar la información contenida en dichos documentos.
        Detectar restricciones académicas como:
            Solapamientos de clases.
            Profesores asignados a varias clases simultáneamente.
            Aulas duplicadas.
            Horarios fuera del rango permitido.
        Generar un informe con los conflictos detectados y posibles sugerencias de resolución.

3. Metodología

    Fase 1: Análisis de requisitos
        Estudio de casos reales de horarios y fichas académicas.
        Identificación de restricciones comunes.

    Fase 2: Procesamiento de documentos
        Uso de técnicas de OCR y NLP para extraer datos de PDFs.
        Normalización y estructuración de la información.

    Fase 3: Desarrollo de la aplicación
        Interfaz para carga de documentos y visualización de datos.
        Algoritmos para detección de conflictos.
        Generación de informes.

    Fase 4: Validación
        Pruebas con horarios reales.
        Evaluación de la precisión en la detección de restricciones.

4. Herramientas y tecnologías

    Lenguajes: Python, JavaScript
    Librerías: PyPDF2, Pandas, SpaCy, Flask/Django
    OCR: Tesseract
    Frontend: HTML/CSS, React (opcional)
    Otros: Git, VS Code
