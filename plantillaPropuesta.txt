Título: Diseño e implementación de una aplicación web para la detección automática de restricciones en horarios académicos a partir de documentos PDF

Descripción: Este Trabajo de Fin de Grado tiene como objetivo el diseño y desarrollo de una aplicación web que facilite la detección automática de restricciones y conflictos en horarios académicos, a partir de documentos PDF que contienen tanto los horarios como las fichas de asignaturas. La propuesta busca automatizar un proceso que actualmente suele realizarse de forma manual, propenso a errores y con un alto coste en tiempo.

La aplicación permitirá a los usuarios cargar documentos PDF, extraer la información relevante mediante técnicas de reconocimiento óptico de caracteres (OCR) y procesamiento de lenguaje natural (PLN), y detectar posibles incidencias como solapamientos de clases, asignación duplicada de aulas o errores en la asignación de profesorado.

Para el desarrollo del sistema se plantea una arquitectura web basada en tecnologías modernas. En el frontend se utilizará React junto con un sistema de estilos como Tailwind CSS o Bootstrap, proporcionando una interfaz intuitiva para la carga de documentos, edición de horarios y visualización de conflictos. En el backend, se empleará Python con el framework FastAPI, integrando herramientas como Tesseract para el OCR y SpaCy para el análisis lingüístico. La manipulación de datos tabulares se realizará con Pandas, y se contempla la generación de informes en distintos formatos. La persistencia de datos se gestionará mediante una base de datos relacional, utilizando SQLite en fase de desarrollo y PostgreSQL en producción, con un ORM como SQLAlchemy o Tortoise ORM. Las entidades principales incluirán grados, asignaturas, profesores, aulas, horarios y restricciones.

Este proyecto pretende ofrecer una solución práctica y escalable que contribuya a mejorar la eficiencia y fiabilidad en la planificación académica.
